in the weeks that build the corresponding features.

## Rules

- Every row of the threat model names a test or a control; a threat with neither is an open risk in
  `docs/architecture/09-risks.md`.
- The security tests required by the constitution (role and isolation tests, privacy test on prompts
  and logs) are listed here with their file paths, so a reviewer can find them.
- Red-team attacks are written by a human, never generated by the agent under test.
