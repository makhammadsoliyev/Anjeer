# 5. PHASE 2 — Delivering the MVP (weeks 7–11)

In this phase the center starts really using the system. The delivery track carries the most weight here — the Angular frontend is written entirely by Claude Code while you focus on backend decisions. In weeks 12–17 you'll learn Angular and take ownership of this code. In parallel, weeks 8–11 include an HTML/CSS minimum (~2 hours/week) — the foundation for Angular in week 12.

> **Phase goal**
>
> By the end of week 9, a teacher can log in, see their group, assign a test, get results, and find a material. That's the MVP — no AI yet, and none needed.
